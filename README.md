# 인접행렬을 활용한 AMR 창고 경로 탐색기

고등학교 『인공지능을 위한 이산수학』 수행평가용 인터랙티브 웹 애플리케이션입니다.  
물류 창고의 연결 구조(노드와 통로)를 **그래프**와 **인접행렬**로 나타내고, **행렬의 거듭제곱(\(A^n\))**을 계산하여 자율이동로봇(AMR)의 **최소 통로 통과 횟수** 및 이동 경로를 탐색합니다.

---

## 📁 파일 구성 (폴더 구조)

```text
amr-warehouse-matrix/
├── index.html       # 웹 애플리케이션 화면 구조 (Semantic HTML5)
├── style.css        # 반응형 UI 디자인 및 시각적 강조 테마 (CSS3)
├── script.js        # 인접행렬 연산, 거듭제곱, 경로 탐색, SVG 그래프 제어 (Vanilla JS)
└── README.md        # 사용 설명서 및 수학적 원리 정리
```

- 별도의 서버 설치, 빌드 도구(Webpack/Vite 등), 외부 패키지, API 키가 필요 없습니다.
- 외부 라이브러리(CDN) 없이 순수 HTML/CSS/JavaScript로 구현되어 인터넷이 없는 오프라인 환경에서도 작동합니다.
- 파일 경로는 모두 상대 경로로 작성되어 있어 로컬 실행 및 **GitHub Pages** 배포에 완벽히 호환됩니다.

## 🚀 실행 방법

### 방법 1. 로컬 브라우저에서 바로 실행
1. 제공된 ZIP 파일의 압축을 풉니다.
2. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 웨일(Whale), 사파리(Safari) 등 웹 브라우저에서 바로 실행합니다.

### 방법 2. GitHub Pages 배포 (웹 링크 공유)
1. GitHub 계정에서 새로운 Public Repository를 생성합니다 (예: `amr-warehouse-matrix`).
2. 이 폴더의 파일들(`index.html`, `style.css`, `script.js`, `README.md`)을 해당 저장소의 루트 디렉토리에 업로드(Commit & Push)합니다.
3. GitHub 저장소의 `Settings` → `Pages` 메뉴로 이동합니다.
4. `Build and deployment` 항목의 `Branch`를 `main` (또는 `master`) / `/(root)`로 지정하고 `Save`를 클릭합니다.
5. 1~2분 후 생성되는 GitHub Pages URL(예: `https://<username>.github.io/amr-warehouse-matrix/`)로 언제 어디서나 접속할 수 있습니다.

## 🧭 주요 기능 및 사용법

### 1. 창고 연결 그래프 및 통로 제어 (좌측 패널)
- **장소(꼭짓점 6개):**
  - 1번 A: 입고 구역
  - 2번 B: 보관 구역 1
  - 3번 C: 보관 구역 2
  - 4번 D: 분류 구역
  - 5번 E: 검수 구역
  - 6번 F: 출고 구역
- **초기 통로(7개):** A–B, A–C, B–D, C–D, C–E, D–F, E–F (양방향 연결)
- **통로 개별 차단 및 복구:**
  - 화면의 버튼 또는 그래프의 통로 선/배지를 클릭하면 해당 통로가 **차단(점선 및 빨간색 배지)** 또는 **복구**됩니다.
  - 양방향 통로이므로 차단 시 인접행렬의 대칭 두 성분이 모두 `0`으로 바뀌며, 즉시 행렬 및 최단 경로가 재계산됩니다.
- **악수 보조정리(Handshaking Lemma) 검증:**
  - 현재 활성화된 통로 수와 인접행렬 모든 성분의 합을 실시간 비교하여 `성분의 합 = 통로 수 × 2`가 항상 성립함을 보여줍니다.
- **초기 상태로 복원:**
  - 상단의 `🔄 초기 상태로 복원` 버튼을 누르면 초기 통로 7개와 A→D 설정으로 즉시 되돌아갑니다.

### 2. AMR 최소 경로 탐색 & 거듭제곱 판정 (우측 패널)
- **최소 통로 통과 횟수 판정:**
  - \(A^1, A^2, A^3, A^4, A^5\) 거듭제곱을 차례로 계산하여 출발지와 도착지에 해당하는 성분이 **처음으로 양수가 되는 지수 \(n\)**을 찾아 최소 횟수로 출력합니다.
  - 출발지와 도착지가 같으면 **0회**로 판정합니다.
  - 5제곱까지 해당 성분이 모두 0이면 **‘도달 불가’**로 명확히 표시합니다.
- **경로 목록 및 시각적 강조:**
  - 해당 최소 이동 횟수를 만족하는 모든 경로 목록이 나열됩니다.
  - 목록에서 원하는 경로를 클릭하면 위 그래프에서 해당 경로의 노드와 통로가 **주황색/골드 하이라이트**로 강조됩니다.

### 3. 교과서 손 계산 비교 기능 (우측 하단)
- 초기 출발지: 1번 A, 도착지: 4번 D
- 초기 \(A^2\)의 1행 4열 손 계산식:
  $$\begin{aligned} (A^2)_{1,4} &= (0\times0) + (1\times1) + (1\times1) + (0\times0) + (0\times0) + (0\times1) \\ &= 0 + 1 + 1 + 0 + 0 + 0 = 2 \end{aligned}$$
- **수학적 의미:** 입고 구역(A)에서 분류 구역(D)까지 통로를 정확히 2번 지나 이동하는 방법이 2가지(A→B→D, A→C→D)임을 의미합니다.
- 프로그램이 실시간 계산한 결과와 나란히 비교하여 일치 여부를 보여줍니다.
- 통로 차단 시에는 *“이 손 계산은 초기 그래프에 대한 값입니다”*라는 안내 문구가 표시되어 계산 오류로 오인하지 않도록 방지합니다.

### 4. 행렬 곱셈 전개식 및 성분 인터랙션 (하단 패널)
- 상단 탭에서 \(A, A^2, A^3, A^4, A^5\) 중 원하는 차수를 선택할 수 있습니다.
- \(A^n = A^{n-1} \times A\) 관계식 형태로 왼쪽 행렬과 오른쪽 행렬, 결과 행렬을 나란히 표시합니다.
- **성분 클릭 인터랙션:**
  - 결과 행렬의 임의의 성분 \((r, c)\)을 클릭하면, **왼쪽 행렬의 \(r\)행**과 **오른쪽 행렬의 \(c\)열**이 동시에 강조됩니다.
  - 아래 전개식 카드에 생략 없는 6개 항의 곱셈과 덧셈식, 그리고 각 경유지(1~6번)별 경로 기여도가 펼쳐집니다.

## 📖 수학적 이론 및 모델의 한계 정리 (수행평가 보고서 참고용)

1. **인접행렬의 성분:** 두 장소가 직접 연결되면 1, 연결되지 않으면 0.
2. **거듭제곱 \(A^n\)의 성분:** 통로를 정확히 \(n\)번 지나서 이동하는 경로(Walk)의 수 (지점/통로 반복 포함).
3. **성분 값과 최소 이동 횟수의 구별:** \(A^2\)의 성분 값 자체(예: 2)는 경로의 가짓수이며, 최소 이동 횟수는 해당 성분이 처음으로 양수가 되는 지수 \(n\).
4. **모델의 한계점:**
   - 통로의 실제 길이(m), 주행 속도, 회전 시간, 통로 폭, 로봇 간 충돌 회피를 고려하지 않은 이산수학적 그래프 모델입니다.
   - 결과값은 ‘최단 물리적 거리’나 ‘최단 시간’이 아닌 **‘최소 통로 통과 횟수(최소 홉 수)’**입니다.
